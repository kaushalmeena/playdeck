# The Games

Every game in the feed, in canonical order — which is also their unlock
order. The feed shuffles the display order on every visit, so this is not the
sequence you will scroll through.

Every game scales its difficulty from your level for that game, and a win
raises it by one.

| Game            | What you do                                                   | Gets harder by                         |
| --------------- | ------------------------------------------------------------- | -------------------------------------- |
| ⚡ Reflex Rush  | Wait for green. Tap fast. Don't jump the gun.                 | Shrinking the reaction window          |
| 🐍 Neon Snake   | Swipe to steer. Eat the orbs, don't eat yourself.             | Faster snake, bigger quota             |
| 🧠 Mind Match   | Match all the pairs before the clock melts.                   | More pairs, less time                  |
| 🚀 Glow Flap    | Tap to thrust. Thread the gates.                              | Narrower gaps, faster scroll           |
| 🎵 Echo Pads    | Watch the pattern. Play it back. It only gets longer.         | Longer sequences, faster playback      |
| ➕ Quick Math   | Mental math against the clock.                                | Bigger numbers, tighter clock          |
| 🎨 Color Clash  | Does the word match its ink? Trust your eyes, not your brain. | More rounds, less time each            |
| 🔍 Odd One Out  | One tile is a little different. Find it.                      | Bigger grid, subtler shade difference  |
| 🔢 Number Order | Tap 1, 2, 3… faster than you can count.                       | More tiles, less time                  |
| 🏃 Dodge Rush   | Three lanes. Falling blocks. Survive.                         | Faster blocks, denser spawns           |
| 🫧 Bubble Pop   | Pop the bubbles. Leave the bombs alone.                       | Faster rise, higher quota, bombs       |
| 🏹 Quick Shot   | Targets shrink fast. Hit every one.                           | Faster shrink, higher quota            |
| 🏗️ Sky Stack    | Drop the block. Keep what overlaps. Reach the top.            | Faster slide, taller goal              |
| 🧩 Pattern Echo | The grid flashes a shape. Paint it back from memory.          | Bigger grid, more lit tiles            |
| 🧺 Star Catch   | Catch the falling stars. Not the bombs.                       | Faster fall, higher quota, bombs       |
| 🧱 Brick Break  | One ball, one life. Clear the wall.                           | More rows, faster ball, smaller paddle |
| 🏓 Keep Up      | Don't let the ball drop. It keeps getting faster.             | More bounces required, faster start    |
| 🪐 Orbit Dash   | Circle the ring. Tap to reverse. Dodge the red arcs.          | Faster orbit, more arcs                |
| 💥 Chain Burst  | One tap sets off a blast. Every orb it touches explodes too.  | Higher quota, faster orbs              |
| 🥁 Beat Ring    | Notes fly into the ring on the beat. Tap as they land.       | Faster tempo, tighter windows, doubles |
| 🔃 Gravity Flip | Tap to flip gravity. Run the corridor, dodge the spikes.     | Faster run, denser spikes, quick pairs |
| 🗂️ Swipe Sort   | Swipe each card into the right bin before its timer runs out. | Shorter timer, more categories, swaps  |
| 🏀 Hoop Flick   | Pull back and flick the ball through the hoop.               | Sliding hoop, then a drifting height   |
