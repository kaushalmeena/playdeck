# The Games

Every game in the feed, in canonical order — which is also their unlock
order: the first eight are free, then each 250 points opens four more. The
feed shuffles the display order on every visit, so this is not the sequence
you will scroll through.

Every game is a self-contained `src/games/<id>.game.html` page. Each scales
its difficulty from your level for that game, and a win raises it by one.
